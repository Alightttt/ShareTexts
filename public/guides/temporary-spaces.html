Temporary Spaces

A shared shelf with its own 8-character code — create it, share the code, let everyone add what's needed. It deletes itself when time is up.

The short version: Create a Temporary Space, get an 8-character code like K7QT-2M4X, and give the code to whoever should join. They enter it at sharetexts.online/space/join and can add text, links, photos, and files — visible to everyone in the space. When the space expires, the code stops working and the content is deleted.

When a Temporary Space is the right tool

A live transfer (the two-device room) moves something now: phone to laptop, this minute. A Temporary Space is for over time and more than two devices:

  • Family trip planning — everyone adds photos, tickets, and addresses to one shelf for the week.
  • Class or workshop — the organizer creates one space; students join with the code and grab the files.
  • Event group — a code announced at the event collects everyone's pictures, with no app and no group chat.
  • Neighborly handoff — leave a space open for the day with the Wi-Fi details, a document, and a link; people dip in when they can.

Create a space and get the code

  1. Open the Spaces screen

    Go to sharetexts.online/space/create and tap Create a space.

  2. Pick a code or generate one

    The code field comes first. Type your own 8 characters or tap Generate. ShareTexts checks live availability as you type — if a code is taken, it suggests a free alternative.

  3. Choose a lifetime

    From 6 hours up to 7 days. The countdown starts when you create the space, and you can close it earlier anytime.

  4. Tap Create space

    The space opens with its code pinned in the header — tap the code chip to copy it.

Share the code — that's the whole handoff

The code is the invitation. Read it out, text it, or show the QR code from the space's share sheet. Whoever should join opens the join screen, types the 8 characters, and taps Join space. A full share link works too — it carries the same access — and the share sheet keeps it under "Share a link instead," because for most people the code is easier to say and remember than a URL.

What the code can and can't do: the code finds the space — that's all. It contains no keys and stores no content. Anyone with the code and an internet connection can join while the space is open, so share it only with people you want inside. Closing the space or letting it expire retires the code everywhere.

What goes in a space

  • Text and links — addresses, notes, passwords for the weekend guest. Links become tappable preview cards.
  • Photos and videos — original quality, no compression.
  • Any file type — PDFs, documents, archives, code. Large files upload in resumable parts, so a dropped connection doesn't restart from zero.
  • From any device — phone, tablet, laptop; everyone with the code sees the same shelf, newest first, with one-tap download.

What happens when the time runs out

Every space shows a live countdown. When it reaches zero the space closes: the code is retired, the stored content is deleted, and anyone arriving with the old code or link sees a calm "no space with that code is open right now" message. The creator can also close the space early from its menu. Temporary means temporary — there is no archive and no account to keep it alive.

Temporary Space vs. two-device room

Two-device room (the classic flow): one sender, one receiver, live WebRTC transfer happening right now. Nothing waits on a server.

Temporary Space: one shared shelf, many devices, content waits for people to arrive during the space's lifetime.

Same privacy model: no accounts, no permanent history, content deleted when the room or space closes.

Frequently asked questions

What is a Temporary Space?

A Temporary Space is a shared shelf that lives for a set time — 6 hours up to 7 days. You create it, get an 8-character space code, and share that code instead of files. Anyone with the code can add text, links, photos, or files, and everyone in the space sees them. When the time is up, the space closes and the content is deleted.

How do I join a Temporary Space with a code?

Open sharetexts.online/space/join, enter the 8-character code the creator gave you, and tap Join space. You can also paste a full space link — it carries the same access. Both the code and the link stop working when the space closes.

Is a space code the same as the 6-digit pairing code?

No. The 6-digit code connects two devices for a live transfer that happens right now. An 8-character space code opens a temporary shared shelf that many people can use over hours or days. The 6-digit code changes every 90 seconds; the space code stays the same until the space closes.

What happens to a Temporary Space when it expires?

The space closes, its code is retired, and the stored content is deleted. Anyone who still has the code or link sees that the space is closed — not an error, just a closed space.
