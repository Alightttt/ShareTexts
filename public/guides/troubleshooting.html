Troubleshooting ShareText

Solutions for common issues with pairing, transferring, and connecting.

Quick fix for most issues: Refresh ShareText on both devices, create a new room, and try again. Most problems are temporary and resolve with a fresh connection.

Pairing Issues

"That code isn't active"

The pairing code has expired. Codes rotate automatically for security.

Fix: Ask the other device to generate a new code. Enter the fresh 6 digits.

"Invalid code" when entering a correct code

This usually means the code expired between when it was shown and when you entered it.

Fix: Request a new code and enter it immediately. Codes are valid for a limited window.

Code is hard to read on mobile

The pairing code display should be large enough to read. If it's too small:

Fix: Use the QR code option instead. Tap "Show QR" on the sending device and scan it with the receiving device.

Connection Issues

"Still connecting" after a long time

The devices are trying to connect but haven't established a link yet.

Fix: Check that both devices have internet. If on different networks, ShareText may use a relay (still secure, slightly slower). Wait up to 15 seconds, then tap "Try again".

"The other device disconnected"

The partner device closed the tab, lost internet, or went to sleep.

Fix: ShareText will try to reconnect automatically. If it doesn't, refresh the page and re-enter the code. Your unsent content is preserved in the composer.

Connection drops during transfer

Unstable Wi-Fi or cellular networks can interrupt the connection.

Fix: Ensure both devices have stable internet. Move closer to the Wi-Fi router. If the transfer was interrupted, try sending again — ShareText will start from where it left off.

Transfer Issues

Transfer seems stuck or very slow

Large files take time, and slow connections make it worse.

Fix: Check the progress indicator. For large files, progress may pause briefly during chunk transfers. If truly stuck, refresh and try again. A faster Wi-Fi connection helps.

Received file looks different or corrupted

This is extremely rare. ShareText verifies file integrity using SHA-256 checksums.

Fix: If the file fails verification, ShareText will show a warning. Try sending again. The checksum comparison ensures what you send is exactly what arrives.

Can't save the received file on mobile

Some mobile browsers handle file downloads differently.

Fix: Tap the Save/Download button on the received file card. If nothing happens, try long-pressing the file preview and selecting "Save to Files" or "Download".

Browser Issues

"Browser Unsupported" message

Your browser doesn't support WebRTC, which ShareText requires for device-to-device connections.

Fix: Update your browser to the latest version, or try a different browser. Chrome, Firefox, Safari (15+), and Edge all support WebRTC.

Camera doesn't open for QR scan

The browser needs camera permission to scan QR codes.

Fix: When prompted, allow camera access. If you denied it, go to your browser's site settings and enable camera permission for sharetexts.online.

General Tips

  1. Refresh both devices — This fixes most temporary issues.
  2. Check your internet — Both devices need an active connection.
  3. Use a fresh code — If pairing fails, generate a new code instead of retrying the same one.
  4. Try a different browser — If one browser has issues, another might work better.
  5. Disable VPN temporarily — Some VPNs interfere with WebRTC connections.
