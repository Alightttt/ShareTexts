About ShareText

ShareText is a free browser-based tool for transferring text, photos, videos, and files between any two devices — without installing an app or creating an account.

What is ShareText? ShareText is a temporary bridge between two screens. You open it on both devices, connect them with a pairing code, and send anything. When you're done, the connection closes. No accounts. No history. No storage.

What ShareText Is

  • A browser-based transfer tool — runs entirely in the browser on any device with a modern browser (Chrome, Safari, Firefox, Edge).
  • A temporary bridge — connects two devices for the duration of a transfer, then closes. There is no persistent account or history.
  • A no-install solution — no app to download, no software to install, no account to create. Just open the website and go.
  • An encrypted transfer — data moves between devices using WebRTC, which provides DTLS encryption in transit.

How Pairing Works

ShareText uses a 6-digit pairing code to connect two devices:

  1. Device A (sender) opens ShareText and clicks "Send something." A 6-digit code appears.
  2. Device B (receiver) opens ShareText and clicks "Receive something," then enters the code.
  3. The devices connect. Transfers happen directly between them.

Pairing codes rotate automatically for security and expire after a limited time. QR codes and share links are also available as alternative connection methods.

How Direct Transfer Works

ShareText uses WebRTC (Web Real-Time Communication) — a browser technology that enables direct peer-to-peer connections. When two devices connect:

  • They establish an encrypted connection using DTLS (the same encryption used by secure web browsing).
  • Files and text move directly between devices, not through a cloud server.
  • If a direct connection isn't possible (due to network restrictions), ShareText uses a relay server as a fallback — the data remains encrypted.

How Agent/API Transfer Works

ShareText supports programmatic access through a temporary agent API. This allows trusted tools to send text or files into an active room. The agent permission is:

  • Room-scoped — only works for the specific room
  • Time-limited — expires automatically
  • Revocable — the room creator can revoke access at any time

What ShareText Does NOT Do

  • Store files or messages on any server
  • Require accounts or login
  • Create permanent transfer history
  • Compress or modify transferred files
  • Support group transfers (two devices only)
  • Work offline (both devices need internet for initial pairing)

Privacy Model

Encryption: All data between devices is encrypted using DTLS via WebRTC. Each transfer uses a unique encryption key.

Storage: ShareText stores no files, no messages, no accounts, and no transfer history. Temporary rooms close automatically when you're done.

Identity: No sign-up, no login, no personal information required. Device names are local identifiers only.

Technical Architecture

ShareText's architecture consists of three layers:

  1. Frontend — A React single-page application served as static files. Handles the UI, pairing flow, file attachment, and WebRTC connection management.
  2. Signaling server — A Cloudflare Worker that coordinates the initial handshake between devices (exchange of connection offers, answers, and ICE candidates). Does not see file contents.
  3. Peer connection — WebRTC DataChannel between the two browsers. Files and text move directly between devices. Encrypted end-to-end.

Who Should Use ShareText

  • Anyone who needs to move a file between two devices quickly
  • People who don't want to install an app for a one-time transfer
  • Users who need to send something between devices they don't own
  • Anyone transferring sensitive content who wants encryption without accounts
  • Developers who need to move code, logs, or files between machines
